mcp(model context protocol)
모델이 외부 도구나 데이터와 연결할 때 사용하는 통신 프로토콜
모델이 외부 시스템에 직접 접근(api는 외부 시스템의 기능을 잠깐 빌려오는 인터페이스)
로컬 mcp와 원격 mcp

controller에 들어온 요청을 agent로 -> agent가 요청을 분석해 필요한 tool(날씨 조회, 가게 검색 등)을 사용하고 조합해 응답
