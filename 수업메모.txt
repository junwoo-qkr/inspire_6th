docker 설치
- sudo apt-get install -y apt-transport-https ca-certificates software-properties-common\
- curl -fsSL https://download.docker.com/linux/ubuntu/gpg | sudo apt-key add -
- apt-key fingerprint
- add-apt-repository "deb [arch=amd64] https://download.docker.com/linux/ubuntu $(lsb_release -cs) stable"
- apt-get update
- apt-get install -y docker-re
- systemctl status docker
- docker version

docker 로그인
- docker login -u junwooqkr5302, 비밀번호에는 토큰 입력

docker 명령어
- docker ps (-a) (-q)
- docker rm <컨테이너이름 or 컨테이너ID>
- docker rmi <이미지이름 or 이미지ID>
- docker run -> pull + create + start
- docker images (-q)
- docker inspect <컨테이너이름 or 이미지이름>
- docker search <이미지이름>
- $(docker ps -a -q) -> rm 시 모든 컨테이너를 지우고 싶을 때

nginx 설치 및 확인
- docker run -d --name webserver -p 80:80 nginx

가상 머신: 호스트 os 위에 hypervisor 위에 게스트 os -> 이미지 안에 os도 포함되어 있어서 용량이 너무 큼
컨테이너: 호스트 os 위에 docker 엔진 위에 컨테이너

이미지: 서비스 운영에 필요한 코드, 파일 등을 묶은 형태
컨테이너: 이미지를 실행한 인스턴스(한 이미지로 여러 컨테이너 실행 가능)
docker host: docker가 컨테이너를 실행할 수 있는 플랫폼을 구성한 것
컨테이너 이미지: 여러 레이어로 구성된 이미지들의 조합
