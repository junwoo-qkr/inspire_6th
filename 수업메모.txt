한 프로그램에서 목적지(파일, 다른 jvm 등)로 데이터를 보내고(Output) 반대로 데이터를 받는(input) 통로: stream
output stream으로는 내보내기, input stream으로는 받기만 가능
serializable: JVM의 객체를 바이트 단위로 변환 -> 다른 시스템에서 활용(파일로 저장, 네트워크로 전송) 가능
xxxStream: 1byte
xxxReader, xxxWriter: 2byte
더 큰 byte를 가지는 클래스로 wrapping 가능
stream은 다 쓰면 close 해야함(garbage가 들어올 수도 있음)
stream은 거의 다 예외를 발생 -> try-catch-finally-try-catch(tcftc, 마지막 t에서 close)

System.in.read(): 1바이트 하나만 읽어들임 -> 한글은 깨짐
->InputStreamReader, BufferedReader로 감싸면 한글 문자열을 받아들일 수 있음

autoClosable: close()를 생략할 수 있는 문법

BufferedReader(FileReader(File())) -> 파일을 읽어들이기

마킹 인터페이스: 추상 메서드가 하나도 없는 것
뭔가를 직렬화하려면 그 자체와 그 안에 있는 것이 Serializable을 implement 해야함
