단일행 함수
- 문자, 날짜, 숫자, 기타 변환 함수
- 행마다 함수를 적용 -> 함수 사용 전과 후가 레코드의 수가 같음

복수행 함수(그룹)
- 테이블 전체에 함수를 적용 -> 함수 사용 전과 후가 레코드의 수가 다름
- MIN, MAX, SUM, COUNT, AVG, ...(WINDOW FUNCTION)
- 복수행 함수는 GROUP BY랑 자주 쓰임
- WHERE 절에는 쓸 수 없음
- SELECT 절에서는 쓸 수 있지만 일반 COLUMN은 쓸 수 없음
- NULL 값은 연산에서 제외 -> NULL도 계산하고 싶다면 IFNULL을 쓰기

정렬

서브그룹(GROUP BY, HAVING)

column의 타입
숫자형, 문자열, 날짜 및 시간 등등

문자열 함수: LENGTH, CONCAT, SUBSTRING, LEFT, RIGHT, INSTR, REPLACE, UPPER, LOWER, TRIM, ...

CHAR: 길이가 정해져있는 문자열
VARCHAR: 가변 길이 문자열

NULL, ''(빈 문자열), 0은 다른거임
