h2 database
- java로 작성된 오픈소스 rdbms
- embedded, server-client 가능
- jpa 연동 가능

POST localhost:60000/user-service/users에 postman으로 접속
- header Authorization에 username는 user, password는 password
- body에 email, name, userId 넣고 보내면 201

localhost:60000/h2-console에 접속
- SELECT * FROM USERS; 실행 ->postman에서 만들었던 user가 나옴

usercontroller에서 requestmapping을 "/"(지금 주석처리된 것)로 바꿔버리면 api gateway로 접속 못함
-> api gateway에서는 prefix로 user-service를 가지는데 이와 충돌됨

POST localhost:8000/user-service/users 후 GET localhost:8000/user-service/users, GET localhost:8000/user-service/users/{userId} 응답을 postman으로 확인
