pod 생성 실습1
vi netflixwweb.yaml
==== yaml 파일 내용 ====
apiVersion: v1
kind: Pod
metadata:
  name: netflixweb-pod
  labels:
    app: nginx-app
spec:
  containers:
  - name: nginx-app
    image: powermvp/netflix:v2.0
    ports:
    - containerPort: 80
    resources:
      limits:
        cpu: 200m
        memory: 256Mi
      requests:
        cpu: 100m
        memory: 128Mi
==== yaml 파일 내용 ====
kubectl apply -f netflixweb.yaml
kubectl describe PODS netflixweb-pod: 포드의 실행 로그

api server: 요청의 인증, 권한 등을 확인
scheduler: 노드의 상태를 보고 새로운 pod를 실행할 노드 선택
etcd: 클러스터의 설정과 상태 저장
controller manager: 원하는 상태를 유지

독립 pod: pod가 하나밖에 없어서 꺼지면 다시 안켜짐
deploy pod: 여러개 만들어서 하나가 꺼져도 다시 복구됨

pod의 이름 구성: deploy-replicaSet-pod

kubectl get deployments.apps,rs,pods
deployments.apps가 rs, rs가 pods를 생성

kubectl delete rs <rs-name>

deployments.apps 삭제
kubectl delete deployments.apps <deployments.apps-name>

deployment 생성

service: k8s의 load balancer와 비슷한 맥락
cluster ip: 내부 연결용
node port: 외부 연결용
load balancer: 외부 연결용
-> service는 pod의 label과 spec.selector.app이 동일한 경우에만 작동

service 생성하기
vi nginx-clusterIp.yaml
==== yaml 파일 내용 ====
apiVersion: v1
kind: Service
metadata:
  name: nginx-app-clusterip
spec:
  selector:
    app: nginx-app
  ports:
  - protocol: TCP
    port: 80
    targetPort: 80
  type: ClusterIP
==== yaml 파일 내용 ====
kubectl apply -f nginx-clusterIp.yaml
kubectl port-forward svc/nginx-app-clusterip 8080:80
curl http://127.0.0.1:8080

aws ecr 이미지로 리소스 생성
- 마스터 노드에 aws cli 설치
kubectl create secret docker-registry ecr-secret \
  --docker-server=<AWS 계정ID>.dkr.ecr.<계정 지역>.amazonaws.com \
  --docker-username=AWS \
  --docker-password="$(aws ecr get-login-password --region <계정 지역>)" \
  --namespace=default
kubectl get secret

AWS ECR로 pod 생성하기
vi awsecr-pod.yaml
==== yaml 파일 내용 ====
apiVersion: v1
kind: Pod
metadata:
  name: nginx
spec:
  imagePullSecrets:
    - name: ecr-secret
  containers:
  - name: nginx
    image: 447839931800.dkr.ecr.us-east-1.amazonaws.com/ecr-nginx:v2.0
    ports:
    - containerPort: 80
==== yaml 파일 내용 ====
kubectl apply -f awsecr-pod.yaml

(또는 yaml 파일 없이 명령어로만 생성)
kubectl run nc \
  --image=447839931800.dkr.ecr.us-east-1.amazonaws.com/ecr-nginx:v2.0 \
  --overrides='{"spec":{"imagePullSecrets":[{"name":"ecr-secret"}]}}'

    metadata:
      labels:
        app: nginx
    spec:
      imagePullSecrets:
        - name: ecr-secret
      containers:
      - name: nginx

kubectl expose deployment nginx-deployment --name nginx-svc --port=80 --type=LoadBalancer
