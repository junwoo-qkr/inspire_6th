암호화 종류
- 대칭키: 암호화/복호화 키가 같음
- 비대칭키(예: RSA Keypair): private key/public key로 나뉨 -> 서로 다른 키로 암호화/복호화

대칭키 실습
- config service에 bootstrap 의존성 추가
- bootstrap 파일에 키 추가
- localhost:8888/encrypt에 POST로 body에 글자 넣어서 요청 -> 암호화된 값이 반환
- decrypt에 POST로 암호화된 값을 넣어서 요청 -> 평문이 반환
- user-service의 설정 파일에서 datasource 주석 처리 -> config server에서 암호화해서 관리(앞에{cipher}를 붙이기)
- config server에서 확인할 수 있음 -> 암호화된 값을 아무나 볼 수 있는 위험이 있음
