예외처리
예외: 예기치 못한 상황(코드가 잘못된 것이 아님)
(에러: 코드 상의 논리적 오류)
예외처리는 예외 발생 시 프로그램을 멈추지 말고 잘 넘기는 핸들링 방법
예외 발생 시점
- 컴파일(IOException)
- 런타임(RuntimeExcetion)
예외처리방법1: try - catch - finally(권장)
예외처리방법2: throws
사용자 정의 예외클래스: 클래스 선언 시 예외를 상속받기
throw: 강제로 예외 발생

try: 예외가 발생 할 수 있는 코드 블럭
catch: 예외 발생 시 실행할 코드 블럭
- catch() 안에는 발생하는 예외를 잘 찾아서 넣어야함
- catch는 하나 이상일 수 있음(각자 다른 에외)
- Exception을 넣어서 싸그리 처리할수도 있음
finally: 예외 발생과 상관없이 실행될 코드 블럭

throw: 강제로 예외 발생시키기
throws: 메서드 안에서 발생할 수 있는 예외를 호출자에게 처리 책임을 넘기는것(짬처리)

mvc 패턴
Presentation Layer: controller class가 있음
Business Layer: Service class가 있음 - 비즈니스 로직 처리
Persistence Layer: dao or repository class가 있음
사용자의 request는 front controller(factory)를 통해 controller로 감
factory는 key: value 형태로 데이터를 관리
dto를 entity로, entity를 dto로 바꿀줄 알아야함
persistence layer는 orm으로 DB와 통신
