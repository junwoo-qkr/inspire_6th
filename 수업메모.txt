jdbc
자바 쪽에서 제공하는 표준 api
수월하게 db를 연동하는 가이드라인
드라이버: .jar 파일
의존성 관리: maven / gradle <- 코드로 드라이버 불러오기(파일을 다운받지 않고)

jdbc 절차
pakage: java.sql.*
- 드라이버 불러오기(driver loading)
- 연결(connection)
- sql 쿼리 수행을 위한 작업(statement(query))
- 실행(execute)
- 결과 핸들링(resultset)
- 연결 종료(close)

https://mvnrepository.com/artifact/org.mariadb.jdbc/mariadb-java-client/3.5.10
여기서 MariaDB java client를 lib 폴더에 받기

connection 하나에 여러 statement(sql)를 만들 수 있음

rset.getString(column 인덱스)

jdbc를 쓰면 mariadbdao.java 파일 통째로 메서드로 구현되어 있음

확장: spring boot extension pack, super mybatis 설치

gradle project 생성
java
spring boot 4.0.8
packaging: jar
configuration: properties
java: 17
dependencies:
- spring boot devtools
- spring configuration processor
- spring web
- spring data jpa
- mybatis
- MariaDB driver
- lombok


main: 자주 사용할 디렉토리
test: 테스트케이스 넣는 디렉토리
build.gradle: dependencies 넣는 곳
- dependencies: group_id : artifact_id : version
- 이 파일에 따라서 jar 파일이 자동으로 깔리고 사라짐
static: js와 이미지 파일 폴더
templates: html 파일 폴더
application.yml: 설정 저장
- application-dev: 개발 시 설정
- application-prod: 배포 시 설정
- application.yml: 맨 처음 무조건 읽는 것, profile 설정을 보고 dev를 볼지 prod를 볼지 결정


spa는 async한 통신: 데이터(json)을 전달
full browsing: page(jsp)를 전달

properties와 yml은 구조가 다름
properties: xxx.xxx.xxx = xxx
yml: xxx:xxx:xxx: xxx
