HAVING: 그룹에 대한 조건
그룹 함수는 일반적으로 group by와 함께 쓰임
GROUP BY에 의존함

GROUP BY 절에 명시된 열과 그룹 함수만 SELECT에 명시될 수 있음

원하는 방식으로 정렬: ORDER BY FIELD

WITH ROLLUP: 계층적 집계 결과

WINDOW 함수: 기존 행을 유지하면서 집계 결과를 추가

mapping-rule: ERD를 바탕으로 관계 스키마 제작

정규화: 데이터의 중복 방지와 효율적인 데이터의 저장(null값 방지)
제1정규화: 테이블의 column이 원자값(하나의 값만)을 갖도록 테이블 분해
제2정규화: 기본키가 여러개(복합키)인 테이블의 column에서 부분 함수적 종속(복합키 중 일부만으로 종속자를 찾음) 제거
제3정규화: 테이블의 column에서 이행적 종속(X->Y, Y->Z 일 때 X->Z) 제거

join: n개의 테이블을 서로 묶어 하나의 결과를 만드는 것
join 조건을 주지 않으면 cartesian product(가능한 조합 모두 출력) 해버림
JOIN TABLE USING (컬럼명): 부모의 외래키와 자식의 기본키 이름이 같지 않으면 못 씀, 별칭을 못 씀
OUTER JOIN: 조건을 만족하지 않는 값을 JOIN
LEFT JOIN: 왼쪽 테이블의 데이터는 무조건 다 나옴
RIGHT JOIN: 오른쪽 테이블의 데이터는 무조건 다 나옴
