docker 구성 요소
- registry: 이미지를 가져오는 곳
- docker host: 가져온 이미지로 컨테이너를 만듦
- client: build, pull, run 등의 명령어 실행

build: 프로젝트 파일로 이미지 생성
run: 이미지로 컨테이너 생성

하나의 이미지는 여러 layer로 구성
컨테이너를 만들면 이미지 레이어(read only)에 컨테이너 레이어(read+write)가 추가됨

docker run -d --name app1 ubuntu:focal
- ubuntu 이미지가 만들어지고 나면 컨테이너가 끝남
docker run -it --name app2 ubuntu:focal /bin/bash
- ctrl + p, ctrl + q를 누르면 컨테이너를 중지하지 않고 접속만 분리
docker run -it --name app3 ubuntu:focal
- 처음부터 접속이 분리되어 있으니 빠져나올 필요가 없음

docker로 MySQL 실행해보기
- docker run -d --name ms -e MYSQL_ROOT_PASSWORD=<비밀번호> mysql -> 컨테이너 생성 및 실행
- docker exec -it ms mysql -u root -p<비밀번호> -> 컨테이너에 접속
- docker exec -it <컨테이너ID> /bin/bash
- cat /etc/hosts
- ls var/lib/mysql

컨테이너는 이미지 레이어 + 컨테이너 레이어
이미지 레이어(read only)
컨테이너 레이어(read, write)
소스 수정은 컨테이너 레이어에
새 이미지를 받아오면 기존 레이어는 놔두고, 바뀐 레이어만 업데이트해서 조합

dockerfile: 컨테이너를 만들도록 도와주는 명령어 집합
- 순서대로 실행됨

dockerfile 생성 후 image push하기
- vi dockerfile 후 아래 입력 / 저장

# Docker file for Ubuntu with OpenJDK 18 and Tomcat 9. 			
FROM ubuntu:18.04									
LABEL maintainer="Jun Woo Park <p40212@gmail.com>"		

# Set environment variables   							
ENV TOMCAT_VERSION 9.0.100
ENV CATALINA_HOME /usr/local/tomcat
ENV JAVA_HOME /usr/lib/jvm/java-17-openjdk-amd64
ENV PATH $CATALINA_HOME/bin:$PATH

# Install JDK & wget packages.
RUN apt-get -y update && apt-get -y upgrade
RUN apt-get -y install openjdk-17-jdk wget

# Install and configure Tomcat.
RUN mkdir $CATALINA_HOME
RUN wget https://archive.apache.org/dist/tomcat/tomcat-9/v${TOMCAT_VERSION}/bin/apache-tomcat-${TOMCAT_VERSION}.tar.gz -O /tmp/tomcat.tar.gz
RUN cd /tmp && tar xvfz tomcat.tar.gz
RUN cp -Rv /tmp/apache-tomcat-${TOMCAT_VERSION}/* $CATALINA_HOME
RUN rm -rf /tmp/apache-tomcat-${TOMCAT_VERSION}
RUN rm -rf /tmp/tomcat.tar.gz

# Expose Tomcat port.
EXPOSE 80

# Start Tomcat
CMD ["/usr/local/tomcat/bin/catalina.sh", "run"]

- docker build -t tomcat:v1.0 .
- docker images로 만들어진 이미지 확인

- docker tag tomcat:v1.0 junwooqkr5302/tomcat:v1.0
- docker push junwooqkr5302/tomcat:v1.0
