apache 이미지 생성을 위한 dockerfile
=================================
FROM ubuntu:22.04
LABEL maintainer = "p40212@gmail.com"

#install apache
RUN apt-get update && apt-get -y install apache2

COPY index.html /var/www/html/index.html

EXPOSE 80

CMD ["/usr/sbin/apache2ctl","-D","FOREGROUND"]

ens5: host(ubuntu)에 대한 네트워크 카드
docker0: host 위에 올라가 있는 docker에 대한 네트워크 카드 -> bridge network
가상 네트워크는 컨테이너 갯수 만큼 더 생김
docker0의 주소는 172.17.0.1 -> 실행하는 컨테이너는 순차적으로 그 다음 주소를 할당받음

apt install net-tools
ifconfig

docker network ls
docker network inspect <컨테이너ID>

brctl show: bridge network에 어떤 네트워크가 물려있는지 표시

bridge
host
none

포트포워딩: container port를 외부로 노출시켜 외부 연결을 허용
-p hostPort:containerPort
-p containerPort -> hostPort는 랜덤
-P -> hostPort는 랜덤, containerPort는 dockerfile의 expose 설정에 따라 달라짐

iptables -t nat -L -n -v의 결과 중 하나
tcp dpt:80 to:172.17.0.2:80
tcp dpt:32768 to:172.17.0.3:80
tcp dpt:32769 to:172.17.0.4:80
-> 컨테이너마다 고유한 내부 ip 부여

사용자지정 bridge network 생성 가능
docker network create --driver bridge --subnet 192.168.100.0/24 --gateway 192.168.100.254 mynet
docker network ls로 확인
docker run -d --name appjs --net mynet --ip 192.168.100.100 -p 80:80 powermvp/marvel-collection

컨테이너로 이미지를 생성할 수 있음(컨테이너 안에는 이미지 레이어가 있기 때문)
docker run -d --name web nginx:1.14
docker rmi -f nginx:1.14
docker commit web nginx1.14

컨테이너를 압축하고, 이를 이용해서 이미지를 만들 수 있음
docker run -d --name nc -p 80:80 nginx:1.14
docker export -o nginx:1.14.tar nc
docker import nginx:1.14.tar new_nginx
-> 이 방법으로 만들어진 이미지는 CMD 또는 ENTRYPOINT 옵션이 없을 수 있음, -g 옵션으로 실행 시 명령어를 추가해주기

이미지를 압축하고, 이를 이용해서 이미지를 만들 수 있음
docker save -o nginx.tar nginx:1.14
docker load -i nginx.tar

이미지 경량화 전략
- 컨테이너의 레이어 수 줄이기: 꼭 필요한 패키지, 파일만 추가
  - dockerfile에서 여러 RUN 명령어를 &&로 묶기(RUN 하나는 레이어 하나이기 때문)
  - 경량화된 이미지 (alpine 등) 사용
  - --no-cache 옵션 넣기
- multi-stage build
