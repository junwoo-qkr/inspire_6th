label
- 리소스의 특성을 분류하고 selector를 이용해 선택
- node, pod, deployment와 같은 모든 리소스에 할당
- key-value 형식

명령어로 pod를 만들면 run=pod이름과 같은 label이 붙음

label-demo.yaml
=========== yaml 파일 내용 ===========
apiVersion: v1
kind: Pod
metadata:
  name: label-demo
  labels:
    environment: production
    app: nginx
spec:
  containers:
  - name: nginx
    image: nginx:1.14.2
    ports:
    - containerPort: 80
=========== yaml 파일 내용 ===========
metadata.labels를 지워버리면 label이 <none>으로 뜸

kubectl label <자원 타입> <자원 이름> [key=value]: label 부여하는 명령어
- --override 옵션으로 기존의 label 변경 가능
kubectl label ... key-: 기존의 label 삭제
kubectl get <자원 타입> -l(--selector) <key=value>: label로 자원 찾기
- -L [key] 옵션으로 해당 key가 있는 자원만 찾기
kubectl get ... --show-labels

node label
- node의 특성을 label로 설정
- 특정 노드에 특정 자원만 배치

nodeSelector
yaml 파일에 key: value 형식으로 선언 -> label이 일치하는 노드에만 pod 배치

annotation
- k8s에 특정 정보 전달(ex: deployment의 rolling update 정보 기록)
- 관리를 위해 필요한 정보 기록

canary 배포
- 기존 버전을 유지한 채 일부만 신규 버전으로 올려서 이상이 없는지 확인
scale 명령어로 canary의 development를 늘리고, stable의 development를 0까지 줄이기(development를 지우지 않아도 됨)

ArgoCD
- k8s 환경에서 GitOps 방식으로 애플리케이션을 배포하고 관리하는 도구
- yaml 파일을 github에서 관리하고, 클러스터 환경에 컨테이너 기반의 앱 배포
- CI/CD(ArgoCD가 yaml 파일을 지속적으로 감시하다가 차이 발생시 자동 동기화)도 적용

git에 push -> git action이 ecr, gitops repo에 전송 -> argocd가 gitops에서 변경사항을 가져옴 -> eks에 배포

argocd 설치
kubectl create namespace argocd
kubectl apply -n argocd -f https://raw.githubusercontent.com/argoproj/argo-cd/stable/manifests/install.yaml <- argoCD를 clusterip 타입으로 설치
kubectl patch deployment argocd-server -n argocd -p '{"spec":{"template":{"spec":{"nodeSelector":{"kubernetes.io/hostname":"k8s-worker1"}}}}}' <- worker1에 고정
kubectl patch svc argocd-server -n argocd -p '{"spec": {"type": "NodePort", "ports": [{"port": 80, "targetPort": 8080, "nodePort": 30070, "name": "http"}, {"port": 443, "targetPort": 8080, "nodePort": 30071, "name": "https"}]}}' <- nodeport 타입으로 변경
http://10.0.2.10:30071으로 접속 확인
kubectl patch svc argocd-server -n argocd -p '{"spec": {"type": "LoadBalancer"}}' <- loadbalancer 타입으로 변경
http://192.168.198.100:443으로 접속 확인

argocd cli 설치
curl -sSL -o argocd https://github.com/argoproj/argo-cd/releases/latest/download/argocd-linux-amd64
chmod +x argocd
sudo mv argocd /usr/local/bin/
kubectl -n argocd get secret argocd-initial-admin-secret -o jsonpath="{.data.password}" | base64 -d; echo <- argocd의 초기 비밀번호 = IuKCapYlVpoYRkNL
argocd login 10.0.2.10:30071 --username admin --insecure
