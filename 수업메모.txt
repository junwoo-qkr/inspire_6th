maven 타입으로 프로젝트 생성

maven의 clean, compile, package
- compile: 코드 컴파일
- clean: 컴파일했던 산출물 삭제
- package: 배포할 수 있도록 .jar 파일 생성

배포된 파일 실행해보기
- target 폴더로 들어가서 java -jar <jar 파일 이름> 입력
- pom.xml이 있는 폴더에서 mvn spring-boot:run 입력

spring cloud Netflix eureka: service discovery(registry) 중 하나
- 각 microservice는 서로의 주소를 알고 있어야 함
- 서로의 주소를 하드코딩하기엔 주소가 바뀔수도 있고 너무 많음
  -> eureka 서버에 각 서버의 정보를 저장, load balancer가 트래픽을 배분

group id는 도메인을 뒤집는게 일반적
예) test.com -> com.test

userService 여러개 동시에 실행하는 방법
1. ide에서 실행하기
- 실행중인 거 설정 -> 구성 -> 편집
- vm 옵션 추가 -> -Dserver.port=60001
- 강사님은 현재 실행중인 걸 그대로 복사할 수 있는데 안되서 직접 설정함
2. ide 내부 터미널로 실행하기
- 터미널에 mvn spring-boot:run "-Dspring-boot.run.jvmArguments=-Dserver.port=60002" 입력
3. 외부 터미널로 실행하기
- userService 프로젝트 폴더에서 터미널 실행
- mvn compile, mvn package 실행
- target 폴더에서 java -jar "-Dserver.port=60003" .\user-service-0.0.1-SNAPSHOT.jar 실행

scale out 할때마다 포트를 설정해주기 번거로움 -> random port 사용하기
- 서비스 실행 시 포트 번호를 0으로 지정하면 자동으로 랜덤한 포트 사용
-> eureka dashboard에는 instance가 1개만 표시됨(전부 포트가 0) -> instance의 id 값도 random하게 설정하기
-> eureka.instance.instance-id= ...
