# 제목: Promise와 async/await를 활용한 비동기 통신과 동적 UI 구현

## 오늘의 한 줄 요약

- 컴포넌트·JSX·컴포지션의 역할과 서로 다른 프론트엔드·백엔드가 JSON으로 데이터를 주고받는 이유를 이해했다.
- Promise의 상태 변화와 체이닝을 익히고, Fetch API의 응답을 `response.json()`으로 변환한 뒤 `async/await`로 실행 순서를 제어했다.
- 서버 데이터를 바탕으로 DOM 요소를 동적으로 만들고, 옵셔널 체이닝과 널 병합 연산자로 누락된 값에 안전하게 대응했다.
- Fetch와 Axios의 응답 처리 차이 및 HTTP 메서드별 CRUD 역할을 비교했다.
- Flexbox·미디어 쿼리·CSS 선택자로 화면을 구성하고 이벤트 대상에 따라 제목·이미지·버튼 문구가 바뀌는 토글 UI를 구현했다.
- 스켈레톤 UI, JWT 헤더 전달, GitHub와 Vercel 배포, AI 도구를 활용한 개발 흐름을 살펴봤다.

| --- | --- |

| JSX | JavaScript 파일 안에서 UI 구조를 함께 표현하는 확장 문법 |
| 컴포지션 | 페이지 컴포넌트가 여러 하위 컴포넌트를 가져와 조합하는 구조 |
| JSON | 서로 다른 기술로 만든 시스템이 데이터를 주고받을 때 사용하는 공통 텍스트 형식 |

| `async` / `await` | async 함수 안에서 Promise가 결정될 때까지 해당 함수의 다음 실행을 기다리게 한다. |

| Axios | Promise 기반 외부 HTTP 클라이언트로 파싱된 응답 데이터는 `response.data`에서 읽는다. |

| 후손 선택자 | `parent child`처럼 깊이에 관계없이 하위의 모든 일치 요소를 선택한다. |

### 컴포넌트·JSX·컴포지션

컴포넌트는 공통 UI 조각뿐 아니라 하나의 독립적인 페이지 역할도 할 수 있다. React 계열의 컴포넌트 파일은 `.js`나 `.jsx`처럼 스크립트 확장자를 사용하며, JSX를 이용하면 JavaScript 로직과 UI 구조를 한 파일에서 표현할 수 있다. 하나의 페이지 안에 여러 하위 UI 컴포넌트를 가져와 감싸고 조합하는 구조를 컴포지션(Composition)이라고 한다.

### 프론트엔드와 백엔드를 연결하는 JSON

Java와 같은 백엔드 언어는 변수의 자료형이 명확한 정적 타입 체계를 사용하고, JavaScript는 실행 중 값에 따라 타입이 달라질 수 있는 동적 타입 체계를 사용한다. 기술과 타입 체계가 다른 시스템이 동일한 데이터 구조를 이해하려면 공통 교환 형식이 필요하며, JSON(JavaScript Object Notation)이 이 역할을 한다.

JSON 문자열을 전달받은 프론트엔드는 파싱을 거쳐 JavaScript 객체나 배열로 바꾸고, 화면 렌더링과 데이터 가공에 사용한다.

```json
{
    "name": "김민준",
    "major": "컴퓨터공학과"
}
```

### Promise의 상태·결과·체이닝

Promise는 ES6에 포함된 비동기 처리 객체다. 서버 요청처럼 언제 완료될지 알 수 없는 작업의 상태와 결과를 관리하며, 중첩 콜백이 계속 깊어지는 콜백 지옥을 줄이고 후속 작업을 체인 형태로 연결할 수 있게 한다. SPA에서 전체 페이지를 새로고침하지 않고 필요한 데이터만 받아 일부 화면을 다시 그릴 때 비동기 처리가 필요하다.

| 처리 단계 | 상태 | 결과 |
| --- | --- | --- |
| 초기 상태 | Pending | `undefined` |
| `resolve(value)` 호출 | Fulfilled | `value` |
| `reject(error)` 호출 | Rejected | `error` |

Fulfilled와 Rejected를 합쳐 Promise의 처리가 끝난 Settled 상태라고 한다. `.then()`은 성공 결과를 처리하고 `.catch()`는 실패를 처리한다. `.then()`도 새 Promise를 반환하므로 후속 작업을 연속해서 연결할 수 있다.

```javascript
const promise = new Promise((resolve, reject) => {
    setTimeout(() => {
        resolve({ status: 200, data: { message: "success" } });
    }, 5000);
});

promise
    .then(response => console.log(response))
    .catch(error => console.log(error));
```

### Fetch API와 응답 본문 변환

`fetch(url)`는 별도 라이브러리 없이 브라우저에서 사용할 수 있으며 Promise를 반환한다. 첫 번째 결과인 `Response` 객체에는 상태와 헤더 등 응답 정보가 들어 있고, 본문 데이터를 JavaScript 객체로 사용하려면 `response.json()`을 호출해야 한다. JSON 변환도 비동기 작업이므로 Promise 체이닝에서는 두 단계의 `.then()`을 거친다.

```javascript
fetch("https://fakestoreapi.com/products")
    .then(response => response.json())
    .then(data => console.log(data))
    .catch(error => console.log(error));
```

### async/await로 비동기 실행 순서 제어

비동기 통신은 응답을 기다리는 동안 다음 코드가 계속 실행될 수 있다. 데이터가 도착하기 전에 렌더링 함수를 실행하면 비어 있는 배열을 순회하는 등 시점 불일치가 생긴다. 함수 앞에 `async`를 붙이고 Promise 앞에 `await`를 사용하면, 해당 async 함수 안에서는 Promise가 결정된 뒤 다음 줄로 진행한다.

`fetch()`와 `response.json()`은 각각 Promise를 반환하므로 두 작업을 모두 기다려야 한다. 오류는 `try...catch`로 함께 처리할 수 있다.

```javascript
const loadData = async () => {
    try {
        const response = await fetch("../server/users.json");
        const data = await response.json();
        return data;
    } catch (error) {
        console.log(error);
    }
};
```

### 서버 데이터로 동적 DOM 요소 생성

서버가 반환한 배열의 개수에 맞춰 카드를 만들 때는 `document.createElement()`로 요소를 생성하고, `textContent`와 속성 프로퍼티로 내용을 채운 뒤 `appendChild()`로 부모·자식 관계를 연결한다. JavaScript에서 `class`는 예약어이므로 동적 요소의 CSS 클래스는 `className`으로 지정한다.

```javascript
const card = document.createElement("div");
card.className = "card";

const name = document.createElement("h3");
name.textContent = obj.username;

card.appendChild(name);
container.appendChild(card);
```

렌더링 함수를 다시 호출할 때 기존 카드를 남겨 두면 같은 데이터가 계속 쌓인다. 반복 렌더링 전에 `container.innerHTML = ""`로 내부를 비운 뒤 현재 배열을 기준으로 새로 그리면 중복을 막을 수 있다. 삭제 버튼에서는 `data.splice(idx, 1)`로 배열 항목을 제거한 뒤 `makeCard()`를 다시 호출해 화면을 갱신했다.

### 옵셔널 체이닝과 널 병합 연산자

원격 데이터에는 예상한 중첩 객체나 필드가 없을 수 있다. `obj.address?.city`는 `address`가 `null` 또는 `undefined`이면 더 깊이 접근하지 않고 `undefined`를 반환한다. 뒤에 `?? "N/A"`를 연결하면 최종 값이 `null` 또는 `undefined`일 때 기본 문구를 표시할 수 있다.

```javascript
phone.textContent = obj.address?.city ?? "N/A";
```

### Flexbox 카드 배치와 스켈레톤 UI

| CSS | 역할 |
| --- | --- |
| `display: flex` | 자식 요소를 주축 방향으로 유연하게 배치 |
| `gap: 20px` | 카드 사이의 행·열 간격 지정 |
| `flex-wrap: wrap` | 컨테이너 너비가 부족할 때 다음 줄로 넘김 |
| `transition`과 `transform` | 카드가 움직일 때 변화를 부드럽게 표현 |

데이터를 불러오는 동안 빈 화면이나 단순 스피너만 보여 주는 대신, 완성될 카드와 비슷한 회색 뼈대 영역을 미리 표시하는 방식을 스켈레톤 UI라고 한다. 실제 레이아웃의 형태를 유지해 화면이 갑자기 바뀌는 느낌을 줄이고 사용자가 체감하는 대기 경험을 개선한다.

### Fetch와 Axios 비교

Axios는 Promise 기반의 외부 HTTP 클라이언트다. HTML에서는 CDN 스크립트를 추가해 사용할 수 있다.

| 항목 | Fetch API | Axios |
| --- | --- | --- |
| 제공 방식 | 브라우저 내장 API | 외부 라이브러리 |
| 요청 결과 | `Response` 객체 | Axios 응답 객체 |
| JSON 데이터 접근 | `await response.json()` | `response.data` |
| 비동기 처리 | Promise, `.then()`, `async/await` | Promise, `.then()`, `async/await` |

```javascript
const response = await axios.get("https://fakestoreapi.com/products");
const data = response.data;
```

### HTTP 메서드와 CRUD 설계

| CRUD | HTTP 메서드 | 역할과 데이터 전달 위치 |
| --- | --- | --- |
| Create | POST | 새 데이터를 요청 본문에 담아 생성 |
| Read | GET | 데이터를 조회하고 필요하면 쿼리스트링 또는 `params`로 조건 전달 |
| Update | PUT | 리소스 전체를 요청 본문의 데이터로 교체 |
| Update | PATCH | 리소스의 일부 필드만 요청 본문의 데이터로 수정 |
| Delete | DELETE | 보통 URL 경로에 대상 ID를 넣어 삭제 |

JWT와 같은 인증 토큰은 상품 정보 같은 비즈니스 데이터와 분리해 HTTP 헤더로 전달한다. 요청의 목적과 리소스 조작 방식에 맞는 HTTP 메서드와 데이터 위치를 선택해야 한다.

### 미디어 쿼리를 이용한 반응형 화면

미디어 쿼리는 화면 너비에 따라 서로 다른 CSS를 적용한다. 커밋의 실습에서는 모바일, 태블릿, 데스크톱 구간을 다음처럼 나눴다.

| 화면 구간 | 조건 |
| --- | --- |
| 모바일 | `320px <= width <= 767px` |
| 태블릿 | `768px <= width <= 1023px` |
| 데스크톱 | `width >= 1024px` |

```css
@media screen and (min-width: 768px) and (max-width: 1023px) {
    body {
        display: flex;
        justify-content: center;
        align-items: center;
    }
}
```

### 자식·후손 선택자와 이벤트 토글

| 선택자 | 범위 | 예시 |
| --- | --- | --- |
| 자식 선택자 `>` | 부모 바로 아래의 직계 자식 | `body > div:first-of-type` |
| 후손 선택자 공백 | 깊이에 관계없이 부모 아래의 모든 일치 요소 | `div h1` |

이벤트 핸들러의 `event.target`은 실제 클릭된 요소를 가리킨다. 커밋의 토글 실습에서는 `isBlue` 상태에 따라 제목의 `textContent`, 이미지의 `src`, 클릭된 버튼의 `event.target.textContent`를 함께 바꾸고 다음 클릭을 위해 상태를 반전했다.

```javascript
document.querySelector("#btn").addEventListener("click", (event) => {
    if (isBlue) {
        title.textContent = "Pink Coffee";
        image.src = "../img/coffee-pink.jpg";
        event.target.textContent = "to Blue";
        isBlue = false;
    }
});
```

## 오늘의 코드 1 - 사용자 데이터로 동적 카드 생성

scriptDOMCreate.html

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Document</title>
    <link href="../css/create.css" rel="stylesheet">
</head>
<body>
    <h2>사용자 목록</h2>
    <div class="container" id="container">

    </div>

    <script>
        let data = [];
        const loadData = async () => {
            try {
                const response = await fetch("https://fakestoreapi.com/users");
                data = await response.json();
            } catch (error) {
                console.log(error);
            }
        }

        const makeCard = () => {
            container.innerHTML = "";
            data.forEach((obj, idx) => {
                const card = document.createElement("div");
                card.className = "card";

                const name = document.createElement("h3");
                name.textContent = obj.username;
                const major = document.createElement("p");
                major.textContent = obj.email;
                const phone = document.createElement("p");
                phone.textContent = obj.address?.city ?? "N/A";
                const delBtn = document.createElement("button");
                delBtn.type = "button";
                delBtn.className = "btn";
                delBtn.textContent = "삭제하기";

                delBtn.addEventListener("click", (e) => {
                    data.splice(idx, 1);
                    window.alert("deleted");
                    makeCard();
                });

                card.appendChild(name);
                card.appendChild(major);
                card.appendChild(phone);
                card.appendChild(delBtn);
                container.appendChild(card);
            });
        }

        const init = async () => {
            await loadData();
            makeCard();
        }
        init();

    </script>
</body>
</html>
```

```css
}
```

`fetch()`와 `response.json()`을 차례로 기다려 사용자 배열을 받은 뒤, `createElement()`, `className`, `textContent`, `appendChild()`로 카드 DOM을 만들었다. `obj.address?.city ?? "N/A"`로 누락된 중첩 값을 처리하고, 삭제할 때는 `splice()`로 배열을 바꾼 뒤 컨테이너를 비우고 다시 렌더링했다. CSS에서는 Flexbox와 `flex-wrap`으로 카드가 화면 너비에 맞춰 줄바꿈되게 했다.

## 어려웠던 점 / 각종 오류

이 코드에서 arr을 쓰지 않고 data로만 코드를 짜고 싶었는데 자꾸 data에 Promise 객체가 저장되어 `data.forEach()`가 작동하지 않았다.

```javascript
let arr = [];
const loadData = async () => {
    await fetch("https://fakestoreapi.com/users")
        .then(response => response.json())
        .then(data => {
            arr = data;
        })
        .catch(error => {
            console.log(error);
        });
    makeCard();
}
```

그래서 아래 코드처럼 바꿨더니 간결하고 가독성도 나아진 것 같았다. `.then()`, `.catch()`는 나랑 안맞나보다..

```javascript
let data = [];
const loadData = async () => {
    try {
        const response = await fetch("https://fakestoreapi.com/users");
        data = await response.json();
    } catch (error) {
        console.log(error);
    }
}
```

`fetch()`와 `response.json()`은 모두 Promise를 반환한다. 따라서 통신 결과를 배열처럼 바로 순회하지 않고 두 Promise의 완료를 각각 기다린 뒤 `makeCard()`를 실행해야 한다는 점을 확인했다.

`scriptPromise.html`의 스타일시트 링크에는 `rel="stylesheet"` 대신 `ref="stylesheet"`가 작성되어 있어 CSS가 연결되지 않는다.

```html
<link href="../css/create.css" rel="stylesheet">
```

`media.css`의 데스크톱 미디어 쿼리는 `body` 블록과 `@media` 블록을 열었지만 닫는 중괄호가 하나만 있어 CSS 문법이 완성되지 않았다. 각 블록을 하나씩 닫아야 한다.

```css
@media screen and (min-width: 1024px) {
    body {
        background: url("../img/bg.jpg") no-repeat;
    }
}
```
