## 오늘 배운 것

### 메서드의 매개변수와 DTO 전달

- 메서드는 입력을 받아 필요한 처리를 수행하고 결과를 반환한다. 선언부의 변수가 매개변수(parameter)이고 호출부에서 전달하는 값이 인자(argument)이다. 반환할 값이 없으면 `void`를 사용한다.
- 제목·내용·이메일을 각각 전달하거나, DTO에 담아 하나의 인자로 전달할 수 있다. 요청 DTO를 getter로 읽고 응답 DTO로 상태와 메시지를 반환하면 호출부가 결과를 사용할 수 있다.
- Java는 값을 복사해 전달한다. 객체를 전달할 때에는 객체를 가리키는 참조값이 복사되므로 호출자와 메서드가 같은 객체를 가리킬 수 있다.

```java
BlogRequestDTO request = new BlogRequestDTO(1, "title2", "content2", "BBB");
BlogResponseDTO response = instance.register2(request);
System.out.println(response.getStatus());
System.out.println(response.getMessage());
```

| 전달 방법 | 특징 |
| --- | --- |
| 개별 값 | 각 매개변수가 입력 의미를 표현하며 개수와 순서를 맞춰 호출 |
| DTO | 연관 데이터를 묶고 getter로 필요한 필드를 읽음 |
| 응답 DTO | 결과 코드·메시지 등 여러 결과를 하나의 객체로 반환 |

- 같은 이름의 메서드를 매개변수 목록을 달리해 정의하면 오버로딩이다. 메서드의 반환 타입은 전달할 결과에 따라 정한다. 블로그의 `register`와 `register2`는 이름이 서로 다른 두 메서드이다.

### 연산자와 조건 선택

| 종류 | 예 | 역할 |
| --- | --- | --- |
| 산술 | `+ - * / %` | 계산, 몫과 나머지 |
| 복합 대입 | `+= -= *= /=` | 계산 후 변수에 대입 |
| 증감 | `++ --` | 1 증가·감소 |
| 관계 | `> >= < <= == !=` | 비교 결과를 논리값으로 반환 |
| 논리 | `!`, `&&`, `\|\|` | 조건 반전과 결합 |
| 논리·비트 | `&`, `\|` | boolean에서는 양쪽 조건 평가, 정수에서는 비트 연산 |
| 삼항 | `조건 ? 값1 : 값2` | 두 값 중 하나 선택 |

- `&&`와 `||`는 왼쪽 값으로 결과가 결정되면 오른쪽을 평가하지 않는다. 정수끼리 나누면 정수 결과를 얻고, 전위·후위 증감은 식에서 사용하는 값의 시점이 다르다.

```java
int count = 1;
System.out.println(count++); // 1을 사용한 뒤 2로 증가
System.out.println(++count); // 3으로 증가한 값을 사용
System.out.println(5 / 2);   // 2
System.out.println(5 % 2);   // 1
String result = count >= 3 ? "PASS" : "FAIL";
```

- `if-else`는 조건의 참·거짓에 따라 분기한다. `switch`는 선택값과 case를 대응시킨다. switch 표현식은 선택 결과를 값으로 사용하며 화살표 규칙에서는 해당 case 실행 후 다음 case로 이어지지 않는다.

```java
String result = switch (number) {
    case 1 -> "거짓말 하지 마세요";
    case 2 -> "또 거짓말 하지 마세요";
    case 3 -> "착하네";
    default -> null;
};
```

### 반복문과 break·continue

| 문법 | 동작 |
| --- | --- |
| `for (초기화; 조건; 증감)` | 조건 검사 후 본문을 실행하고 증감식으로 이동 |
| `while (조건)` | 먼저 조건을 검사하고 참이면 본문 실행 |
| `do { ... } while (조건);` | 본문을 먼저 실행하고 조건 검사 |
| `break` | 가장 가까운 반복문 또는 switch 종료 |
| `continue` | 현재 반복의 나머지를 건너뛰고 다음 회차로 진행 |
| `break outer` | `outer`로 표시한 바깥 반복문 종료 |

```java
for (int i = 1; i <= 5; i++) {
    if (i == 2) continue;
    if (i == 4) break;
    System.out.println(i); // 1, 3
}
```

```java
int count = 0;
boolean falseCondition = false;
while (falseCondition) { count++; } // 조건이 거짓이면 0회
do { count++; } while (falseCondition); // 본문을 최소 1회 실행
```

- 중첩 반복문은 바깥 회차 하나마다 안쪽 반복을 수행한다. 구구단은 단과 곱할 수를 두 반복문으로 표현한다. `printf`의 `%d`, `\t`와 줄바꿈을 이용해 출력 모양도 조절한다.

```java
outer:
for (int dan = 2; dan <= 9; dan++) {
    for (int n = 1; n <= 9; n++) {
        if (dan == 5) break outer;
        System.out.printf("%d * %d = %d\t", dan, n, dan * n);
    }
    System.out.println();
}
```

### JVM 메모리와 객체의 생명주기

| 영역·개념 | 핵심 역할 |
| --- | --- |
| Heap | 인스턴스와 배열을 위한 메모리. 도달할 수 없는 객체는 GC 회수 대상 |
| JVM Stack | 스레드마다 메서드 호출 프레임을 관리. 호출·종료는 LIFO 흐름 |
| Method Area | 클래스별 구조와 메서드 코드 등 클래스 정보를 관리 |
| 문자열 풀 | 같은 문자열 리터럴 등을 공유하기 위한 관리 구조 |

- 지역 참조 변수가 사라져도 다른 경로가 객체를 가리키고 있으면 객체를 계속 사용할 수 있다. 회수 대상이 되는 시점과 실제 GC 실행 시점은 구분하며, 실제 회수 정책은 JVM 구현과 설정에 따른다.
- 이 표는 동작을 이해하기 위한 개념 구분이다. 문자열 풀과 `static` 필드의 물리적 저장 위치까지 하나의 고정된 메모리 지도처럼 해석하기보다는 객체·클래스·호출 프레임의 역할에 집중한다.

### static과 final의 역할

- `static` 필드·메서드는 클래스에 속하고 인스턴스 멤버는 개별 객체에 속한다. 정적 메서드에서도 객체 참조를 확보하면 인스턴스 멤버에 접근할 수 있다. 정적 필드 초기화는 클래스 초기화 과정과 연결된다.
- `final` 변수는 한 번 대입한 뒤 다시 대입할 수 없다. `static final`을 함께 사용하면 클래스에 속한 상수를 표현할 수 있다. 참조 변수의 재대입 제한과 참조 대상 객체의 변경 가능성은 구별한다.

```java
class StaticDemo {
    public String message = "그냥 변수";
    public static String staticMessage = "static 변수";
    public static final int MAX_TRIES = 10;
}
```

```java
StaticDemo demo = new StaticDemo();
System.out.println(demo.message);
System.out.println(StaticDemo.staticMessage);
```

### 문자열의 동일성·내용 비교와 가변 문자열

- `String`은 불변 객체이다. 동일한 문자열 리터럴은 같은 객체를 공유하고 `new String()`은 새 객체를 생성한다. 참조 타입에 대한 `==`는 같은 객체를 가리키는지 비교하고, `String.equals()`는 문자 내용을 비교한다.

```java
String a = "AAA";
String b = "AAA";
String c = new String("AAA");
System.out.println(a == b);      // true
System.out.println(a == c);      // false
System.out.println(a.equals(c)); // true
```

- `length()`는 문자열 길이, `charAt()`은 지정 인덱스의 `char`, `substring()`은 지정 범위의 문자열을 반환한다. 인덱스는 0부터 시작하고 끝 인덱스는 포함하지 않는다.

```java
String text = "ABC";
System.out.println(text.length());      // 3
System.out.println(text.charAt(0));     // A
System.out.println(text.substring(1));  // BC
```

- 문자열을 반복해서 조합할 때 가변 버퍼를 사용할 수 있다. `StringBuffer`는 동기화된 메서드를 제공하고, `StringBuilder`는 동기화를 제공하지 않아 단일 스레드의 문자열 조합에 적합하다. 수업에서는 `StringBuffer.append()`를 활용했다.

```java
StringBuffer buffer = new StringBuffer();
buffer.append("Java").append(" Study");
System.out.println(buffer.toString()); // Java Study
```

### 숫자 맞추기 게임의 입력과 반복 흐름

- `(int) (Math.random() * 100) + 1`로 1~100의 정수를 만들고, `Scanner(System.in)`으로 입력을 읽는다. 정답과 비교해 Up·Down 힌트를 제공하고 최대 10번까지 시도하도록 반복을 제한한다.
- 블로그의 게임 메서드는 정답이면 성공 메시지를 즉시 반환하고, 반복을 모두 마치면 실패 메시지를 반환한다. `for`, `while`, `do-while`로 같은 규칙을 표현하면서 조건 검사와 시도 횟수 증가 위치를 비교했다.

```java
int answer = (int) (Math.random() * 100) + 1;
for (int tries = 1; tries <= 10; tries++) {
    if (GuessGameCore(answer)) {
        return "You got it in " + tries + " tries.\nThe answer was " + answer;
    }
}
return "You lost. The answer was " + answer;
```

## 어려웠던 점 / 각종 오류
